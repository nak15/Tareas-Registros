# Tareas-Registros

Registro de tareas y pendientes de la universidad.

- [`TAREAS.md`](TAREAS.md) — lista de pendientes con estimados de tiempo y estado.

## Cómo se usa

Cada tarea lleva un estimado en horas y un estado: `[ ]` pendiente, `[~]` en curso, `[x]` terminada.
Al avanzar, se marca la casilla y se actualiza la fecha de "Última actualización".

## Skills

Este repo instala skills de Claude Code en `.claude/skills/`:

- `caveman` — modo de respuesta ultra-comprimido. Se activa con `/caveman` (niveles: `lite`, `full`, `ultra`, `wenyan-lite`, `wenyan-full`, `wenyan-ultra`) y se apaga con "stop caveman".
